## v0.9.0 - 2026-11-20

Five names are added: one in `proc` (`LocalFileName`) and four in `testenv` (`KeepsModes`, and `Running`'s `Stdout`, `Stderr` and `Terminate`). No name is removed and no signature changes. Every name added is experimental, as every name of the module is. Nothing changes in `gitenv`, `load`, `sandbox` or `service`. go.mod and go.sum require the same modules at the same versions. The tagged tree is 12,463 non-test Go lines outside `internal/` (`task size`), at its ceiling of 12,463, up 124 from v0.8.1's 12,339: 9,619 in the runtime packages and 2,844 in `testenv`.

### For a v0.8.1 caller

- Nothing changes. Every change is a name added, and a program built with v0.9.0 that calls none of them runs as it did with v0.8.1.

### proc

- Added: `LocalFileName(id)` is the file name the program `id` has on the system this process runs on, as `FileName` gives it for that system: `id.exe` on Windows, `id` elsewhere, for a caller that doesn't name the system. `FileName(goos, id)` is as it was, for code that names every system's name. An id that already ends in `.exe` is given a second `.exe` on Windows.

### testenv

- Added: `KeepsModes(t)` is whether the system keeps POSIX mode bits on a file, false on Windows, and skips nothing, so a test can read a mode in only the assertions that need one and check the rest on every system. `Modes(t)` is a skip where it is false.
- Added: `Running.Stdout()` and `Running.Stderr()` each give a new `io.Reader` of that stream from its start, which a test may read while the program runs, for example its readiness line before `Wait`. A read waits for more output, or for the program's end and then `io.EOF`. The output is kept, not piped through the test, so a program never waits on a test that doesn't read, and `Wait` still reports all of it.
- Added: `Running.Terminate()` sends SIGTERM on Unix. On Windows, which has no SIGTERM, it sends nothing and its error wraps `errors.ErrUnsupported`. Once the program has ended it sends nothing and returns `os.ErrProcessDone`, as `Interrupt` and `Kill` do.
