## v0.8.1 - 2026-11-20

The library's code and API are unchanged from v0.8.0: no name is added, removed or changed, and `API.txt` is the same. go.mod and go.sum require the same modules at the same versions. Only the library's own tests changed, three test files of `proc` on Linux: one test now reaches the call by which the shim enters its folder, and one waits on the kill of the run's tree where it waited on a 10 s clock. The tagged tree is 12,339 non-test Go lines outside `internal/` (`task size`), at its ceiling of 12,339, the same as v0.8.0's: 9,609 in the runtime packages and 2,730 in `testenv`.

### For a v0.8.0 caller

- Nothing changes. A program built with v0.8.1 runs as it did with v0.8.0.
