## v0.10.0 - 2026-11-20

Two names are added, both methods of `testenv.Binary`: `Dir` and `Env`. No name is removed and no signature changes. Both are experimental, as every name of the module is. Nothing changes in `gitenv`, `load`, `proc`, `sandbox` or `service`. go.mod and go.sum require the same modules at the same versions. The tagged tree is 12,510 non-test Go lines outside `internal/` (`task size`), at its ceiling of 12,510, up 47 from v0.9.0's 12,463: 9,619 in the runtime packages and 2,891 in `testenv`.

### For a v0.9.0 caller

- Nothing changes. Both changes are names added, and a test built with v0.10.0 that calls neither runs as it did with v0.9.0.

### testenv

- Added: `(*Binary).Dir(dir)` and `(*Binary).Env(kv...)` each return a copy that runs the same build in another folder, or with each `NAME=value` laid over the clean environment, by `Run`, `RunInput` and `Start` alike. The receiver is unchanged, so each test under `t.Parallel` can take its own copy. An `Env` entry without `=` is refused, wrapping `ErrRefused`: such a copy runs nothing, and `Run` and `RunInput` report the refusal as they report a failed build, with code -1 and the reason on Stderr, while `Start` returns it as its error.
